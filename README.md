# BMW Worldwide Sales Analysis (2010 - 2024)

A complete end-to-end data analytics project exploring BMW’s global sales performance using SQL, Python (Pandas), and Power BI.  
This dashboard helps understand how different BMW models, regions, fuel types, and years contribute to overall sales and revenue.

---

## 1. Project Objective
The goal of this project was to analyze BMW’s sales dataset and build an interactive Power BI dashboard that answers important business questions:

- Which BMW models generate the most revenue?
- Which regions contribute the highest sales?
- How do fuel types and transmission types influence performance?
- What does the yearly revenue trend look like?
- How does each model perform individually?

This project showcases skills in data cleaning, EDA, DAX, visualization, and dashboard design.

---

## 2. Key Insights from the Dashboard

### Overall Metrics
- **Total Revenue:** $19T  
- **Total Sales:** $253M   
- **Average Price:** $75K  
- **Revenue Per Sale:** $75.04K  

### Model Insights
- **Top Revenue Models:** 7 Series, 3 Series, i8, X1, 5 Series  
- Electric models (i3, i8) are premium-priced and drive strong revenue.  
- All models maintain stable yearly sales.

### Regional Insights
- **Asia leads** with highest revenue (~$3.25B).  
- Europe and North America are close behind.  
- Sales distribution across regions is well balanced.

### Fuel Type Insights
- **Hybrid** and **Diesel** vehicles dominate sales volume.  
- Electric models contribute strongly to premium revenue.

### Trend Insights
- Revenue shows a steady upward trend from **2010–2024**.  
- Most records fall under **High Sales Classification**.

### Model View Page
Each model displays:
- Model Revenue  
- Model Sales  
- Average Model Price  
- Average Mileage  
- Average Engine Size  
- Full-size image from GitHub URLs  

This helps compare model-level performance visually and analytically.

## 3. Tech Stack

### SQL
- Used for cleaning, standardizing, and improving the raw data.  
- Removing duplicates and invalid fields.

### Python (Pandas, Matplotlib, Seaborn)
- Used for exploratory data analysis (EDA).  
- Identifying trends, patterns, outliers, and correlations.

### Power BI
- Used for building the interactive dashboard.  
- DAX measures for totals, averages, and KPIs.  
- Slicers, drillthrough, page navigation.  
- Image URLs displayed through GitHub raw links.

### GitHub
- Used for hosting project files and image URLs.  
- Version control and portfolio presentation.

## 4. Dashboard Purpose & Features

### Business Purpose
BMW needs insight into how models, regions, and fuel types perform to guide the decisions in marketing, production, and pricing.

### Dashboard Goals
- Provide a clear overview of overall sales and revenue.  
- Identify top-performing models and regions.  
- Understand long-term revenue trends.  
- Compare fuel type and sales classification performance.  
- Allow users to explore each model individually.

### Key Features
- KPI cards (Revenue, Sales, Avg Price, Revenue Per Sale)  
- Top 5 Models by Revenue  
- Revenue by Model  
- Revenue by Region  
- Sales by Region  
- Sales by Model  
- Sales Classification Breakdown  
- Revenue Trend by Year  
- Fuel Type Performance  
- **Model View Page** with high-quality images and model-specific metrics  
- Clean slicers and page navigation buttons

## 5. Dataset

The dataset includes BMW sales data from **2010 to 2024** with **50,000 rows**.

**Dataset Source:** https://www.kaggle.com/datasets/ahmadrazakashif/bmw-worldwide-sales-records-20102024 

**Tools Used:** SQL | Python(Pandas) | Power BI 

**Project Type:** Sales | Data Visualization


### Columns Included
- Model  
- Year  
- Region  
- Color  
- Fuel Type  
- Transmission  
- Engine Size (L)  
- Mileage (KM)  
- Price (USD)  
- Sales Volume
- Revenue  
- Sales Classification  
### Data Preparation
- Cleaned in SQL  
- Exploratory data analysis in Python  
- Visualized in Power BI
